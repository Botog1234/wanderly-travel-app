\# Wanderly



Wanderly helps travelers explore a destination, plan visits, and check the weather for their trip dates.



\## What you can do



\- Search for countries,(search bar or world icon) attractions, and accommodation.



\- Search and filter places by category.



\- Plan hotel stays and attraction visits.



\- Check forecasts and get an outdoor-day suggestion.



\- View saved plans on the calendar.



\- Reopen cached place results offline.



\## Data and APIs



\- \*\*Geoapify\*\* provides place search and geocoding. Its free plan currently includes 3,000 credits per day. \[Pricing](https://www.geoapify.com/pricing/) · \[Terms](https://www.geoapify.com/terms-and-conditions/)



\- \*\*Open-Meteo\*\* provides trip-date forecasts. Its free API is for non-commercial use and currently allows up to 10,000 calls per day. \[Pricing](https://open-meteo.com/en/pricing/) · \[Terms](https://open-meteo.com/en/terms)



\- Country search uses the country-data API configured in `world\_Search.dart`. Check that API’s current limits and terms before distribution.
